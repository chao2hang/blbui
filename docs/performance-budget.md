# 性能预算（0.0.14 起）

性能预算以固定 Chromium 的可重复合同为准，不把开发机 DevTools 数据当成发布门禁。`bun run performance:check` 会在文档宿主中插入 10,000 行 DataGrid，并验证：

- 虚拟窗口只渲染不超过 30 行，`aria-rowcount` 仍为 10,000。
- 首次大数据集渲染少于 1,000ms，滚动窗口更新少于 500ms。
- 主题切换完成少于 500ms。
- 500ms 采样窗口不少于 20 FPS；固定 runner 资源变化时应先记录证据再调整预算。

真实业务宿主接入后，应再用业务数据形状复核列渲染器、服务端分页、筛选和主题切换；复杂单元格不得把整行重新创建为大型组件树。
