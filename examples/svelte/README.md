# BLBUI Svelte playground

This is a small, real Vite + Svelte 5 application covering the shared Shell and
PageHeader layout wrappers, tabs, filter input, table, pagination and dialog
state. Install its package manifest and run `npm run dev` to validate the
published Svelte adapter independently.
The parity screen also exercises the shared async data contract: error/retry,
permission-denied and a named permission slot.
